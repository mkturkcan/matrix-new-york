World model game demo

Matrix New York

Pick any spot in New York City. We pull the real Street View panorama, erase the cars around you, drop in your own 3D car, and let the Matrix-Game-3.0 world model do the rest: every frame after the first is generated.

GitHub repo Matrix-Game-3.0 MeshFleet streetlevel

Drive the city

Each clip starts from a single real Street View frame. Everything after that comes from the world model, driven by keyboard and steering actions: W for throttle, yaw for the steering wheel, short strafes for lane changes. Matrix-Game-3.0 is a first-person model, so it would drive straight through the car in the first frame. Like a game engine drawing the player over the world, we re-draw the same car layer on every frame and let it lean with the steering.

How a scene is built

One Python script turns a latitude and longitude into a playable first frame: find the nearest official Street View panorama, look down the road, erase the vehicles near the camera, and drop in a MeshFleet car rendered from a chase camera.

Controls (interactive mode)

In interactive mode the world model pauses after every chunk and waits for your next command.

wgas
sbrake / reverse
a / dsteer left / right
wa / wdaccelerate through a turn
z / clane change left / right
qcoast

Run it

# 1. build first frames (curated scenes, a random NYC spot, or your own lat/lon)
python -m nycdrive.prepare_inputs                 # curated highway + downtown scenes
python -m nycdrive.prepare_inputs --random        # random spot in NYC
python -m nycdrive.prepare_inputs --lat 40.7580 --lon -73.9855 --name my_spot

# 2. drive: scripted route to video, or play interactively
python -m nycdrive.drive --scene data/inputs/fdr_drive --route highway
python -m nycdrive.drive --scene data/inputs/times_square --interactive
